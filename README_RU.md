# SecNote 1.4.2

**Небольшое обновление файлового хранилища на базе рабочей SecNote 1.4.1.** Сохранены существующие заметки, чек-листы, биометрия, секретный пароль уничтожения, криптография и остальные настройки.

- **Название:** SecNote
- **Package ID / namespace:** `infernics.notes`
- **Version:** `1.4.2` (`versionCode = 10`)
- **Минимальный Android:** 8.0 (API 26)
- **Compile SDK:** 35
- **Java:** 17
- **Gradle:** 8.7

## Что изменено в 1.4.2

- Убран дополнительный диалог «Переместить файл в защищённое хранилище?». После выбора документа импорт начинается сразу.
- Добавлен множественный выбор файлов в системном файловом менеджере (`ACTION_OPEN_DOCUMENT` + `EXTRA_ALLOW_MULTIPLE`). Обрабатываются и `ClipData`, и одиночный `data` URI; повторяющиеся URI удаляются из списка.
- Файлы импортируются последовательно. Для каждого сначала создаётся и синхронизируется зашифрованная копия, и только после успешной фиксации выполняется best-effort перезапись и удаление оригинала.
- Ошибка обработки одного файла не прерывает импорт остальных. После завершения показывается количество добавленных файлов, удалённых/перезаписанных оригиналов и список неудачных элементов.
- Исправлено принудительное закрытие защищённой сессии после возврата из системного файлового менеджера. Отмена выбора, успешный импорт, выбор папки для экспорта и возврат из системного диалога больше не вызывают немедленную блокировку.
- На время системного выбора документов таймер автоблокировки приостанавливается; после возврата он начинает отсчёт заново. Если Android завершит процесс приложения, повторный запуск всё равно потребует разблокировку.

## Что сохранено

- Обычные заметки и встроенные чек-листы.
- Автосохранение редактора, ручная сортировка и настройки автоблокировки из 1.4.1.
- AES-256-GCM шифрование заметок и файлов.
- Галерея изображений и список документов в файловом хранилище.
- Массовое выделение, массовая расшифровка и удаление.
- Биометрическая разблокировка через Android BiometricPrompt и Android Keystore.
- Блокировка снимков экрана через `FLAG_SECURE`.
- Секретный пароль экстренного уничтожения и возобновляемая очистка.
- Светлая и графитовая тёмная темы.

## Как работает импорт нескольких файлов

1. Пользователь нажимает «Добавить» в файловом хранилище.
2. Открывается системный файловый менеджер Android с разрешённым множественным выбором.
3. Можно выбрать один или несколько файлов.
4. После подтверждения выбора SecNote сразу начинает импорт — дополнительного диалога подтверждения нет.
5. Каждый файл шифруется и сохраняется в приватном хранилище SecNote. После фиксации зашифрованной копии приложение пытается перезаписать и удалить оригинал.
6. По завершении показывается сводка. Если системный провайдер не разрешил удалить оригинал, SecNote сообщает об этом.

## Важное ограничение удаления оригиналов

Перезапись оригинала и его удаление выполняются только в пределах разрешений, которые предоставляет Android-провайдер выбранного документа. Облачные провайдеры, виртуальные документы и некоторые файловые менеджеры могут не поддерживать запись или удаление. Кроме того, Android-приложение не может гарантировать физическое уничтожение старых блоков NAND/flash-памяти из-за wear levelling. Поэтому приложение сообщает фактический результат best-effort операции и не обещает сертифицированное физическое стирание.

## Исправление блокировки после системного выбора

Причиной предыдущего поведения было то, что возврат из системного файлового менеджера трактовался как обычный выход приложения в фон: lifecycle-обработчик принудительно обнулял текущую криптографическую сессию. В 1.4.2 для вызванных пользователем системных экранов выбора документов введено отдельное состояние сохранения сессии. Оно применяется к импорту, экспорту и выбору папки для массовой расшифровки; политика биометрической аутентификации остаётся отдельной.

## Совместимость и миграция с 1.4.1

- `applicationId` остаётся `infernics.notes`.
- Подпись APK остаётся прежней: `signing/secure-notes-debug.keystore`.
- Форматы зашифрованных заметок и файлов не меняются.
- Миграция данных не требуется.
- Устанавливайте APK поверх SecNote 1.4.1. Не удаляйте приложение и не очищайте его данные перед обновлением.
- **Не заменяйте и не удаляйте прежний keystore** — без него Android может отказаться устанавливать обновление поверх существующей версии.

## Онлайн-сборка GitHub Actions

Workflow находится в `.github/workflows/build-apk.yml`. Он проверяет идентификатор приложения, версию и наличие ключевых файлов, затем запускает:

```bash
gradle clean testDebugUnitTest assembleDebug --no-daemon --stacktrace
```

После успешного выполнения `app-debug.apk` появляется в разделе Artifacts.

Подробная инструкция: `GITHUB_UPDATE_GUIDE_RU.txt`.

## Подпись и приватность

В архиве находится `signing/secure-notes-debug.keystore`, используемый для подписи debug APK. **Репозиторий должен оставаться Private.** Не публикуйте keystore и не отправляйте секретный пароль уничтожения в GitHub issues, README или коммиты.

## Проверки

Workflow проверяет наличие множественного выбора (`EXTRA_ALLOW_MULTIPLE`), обработчика `ClipData`, batch-import API и маркера сохранения сессии для системных picker-экранов. Затем выполняет JVM unit-тесты и Android-сборку. Статические проверки не заменяют проверку на реальном смартфоне: после сборки отдельно протестируйте импорт одного и нескольких файлов, отмену выбора и возврат из файлового менеджера при разных настройках автоблокировки.
