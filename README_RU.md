# SecNote 1.4.0

Обновление защищённых заметок и файлового хранилища на базе рабочей SecNote 1.3.3.

- **Название:** SecNote
- **Package ID / namespace:** `infernics.notes`
- **Version:** `1.4.0` (`versionCode = 8`)
- **Минимальный Android:** 8.0 (API 26)
- **Compile SDK:** 35
- **Java:** 17
- **Gradle:** 8.7
- **Android Gradle Plugin:** 8.6.1
- **Kotlin:** 1.9.24

## Что нового

- На главном экране у обычных записей не выводится отдельная подпись «Заметка».
- Ручная сортировка заметок перетаскиванием за маркер справа. Новый порядок записывается в зашифрованные файлы заметок и сохраняется после перезапуска.
- Автосохранение редактора с debounce 400 мс после последнего изменения. Сохраняются заголовки, текст заметок, строки и состояния чек-листов. Дополнительное сохранение запускается при выходе из редактора и при уходе приложения в фон; отдельной кнопки «Сохранить» нет.
- Настраиваемая автоблокировка: **мгновенно / 1 минута / 5 минут**. Если Android завершит процесс приложения, при следующем запуске оно всегда будет заблокировано.
- Удаление заметок и зашифрованных файлов включает best-effort перезапись собственных файлов перед удалением.
- При помещении файла в хранилище SecNote сначала создаёт зашифрованную копию, синхронизирует данные и метаданные на диск, и только после этого пытается перезаписать оригинал и удалить его через системный файловый провайдер.
- Сообщение **«Попытки исчерпаны»** перед экстренным уничтожением показывается 4 секунды вместо 1,1 секунды.

Сохранены функции предыдущей версии:

- Заметки и встроенные чек-листы с отдельной строкой на каждый пункт.
- AES-256-GCM шифрование заметок и файлов.
- Файловая галерея изображений и отдельный список документов.
- Массовое выделение файлов, массовая расшифровка и удаление.
- Биометрическая разблокировка через Android BiometricPrompt и Android Keystore.
- Блокировка снимков экрана и записи экрана через `FLAG_SECURE`.
- Секретный пароль экстренного уничтожения, вводимый в обычное поле разблокировки.
- Светлая и графитовая тёмная темы.

## Экстренное уничтожение

Секретный пароль устанавливается в **Настройки → Безопасность → Секретный пароль уничтожения**. Он должен быть отдельным от основного и содержать не менее 8 символов.

При вводе секретного пароля в то же поле, где вводится основной пароль:

1. Сначала устойчиво записывается маркер незавершённой очистки в `noBackupFilesDir`.
2. Отображается сообщение **«Попытки исчерпаны»** в течение 4 секунд.
3. Начинается очистка без дополнительного подтверждения и без возможности отмены.
4. Блокируются новые операции с заметками и файлами, ожидается завершение уже начатых операций.
5. Уничтожаются ключи SecNote в Android Keystore, биометрическая привязка, соль основного пароля, verifier секретного пароля, заметки, списки, файловое хранилище, кэши и настройки.
6. Маркер удаляется только после успешной очистки. Если процесс прервётся или очистка завершится ошибкой, старые данные не открываются; при следующем запуске очистка продолжается или предлагается повтор.
7. После успешной очистки открывается первоначальная настройка пустого SecNote.

## Удаление и ограничения физической перезаписи

SecNote перезаписывает нулями и удаляет собственные файлы, где это возможно. При импорте оригинал перезаписывается только если выбранный Android-провайдер предоставляет доступ к записи и seekable-дескриптору; затем приложение запрашивает удаление. Интерфейс сообщает, если провайдер не разрешил одну из операций.

Обычное Android-приложение **не может гарантировать физическое уничтожение каждого старого блока NAND/flash-памяти** из-за wear levelling, кешей, файловых версий, облачной синхронизации и особенностей сторонних провайдеров. Перезапись является best effort, а не сертифицированным forensic erase. Приложение не удаляет внешние копии, резервные копии Android, облачные версии, копии в корзине стороннего провайдера или оригиналы, к которым провайдер не предоставил доступ.

## Совместимость и миграция с 1.3.3

Обновление `1.3.3 → 1.4.0` сохраняет:

- `applicationId = infernics.notes`;
- прежнюю подпись APK из `signing/secure-notes-debug.keystore`;
- формат JSON заметок и формат AES-GCM файлового хранилища;
- существующие заметки, чек-листы и зашифрованные файлы без перешифрования.

При первом успешном входе после обновления старая 16-байтная соль автоматически оборачивается отдельным неэкспортируемым AES-256-GCM ключом Android Keystore. Миграция выполняется при входе как по основному паролю, так и по биометрии. Существующий биометрический ключ остаётся действительным, так как ключ содержимого не меняется.

Не удаляйте приложение перед установкой обновления и не очищайте его данные. Устанавливайте новый APK поверх SecNote 1.3.3. **Не заменяйте и не удаляйте прежний keystore** — без него Android не установит обновление поверх старой версии.

## Онлайн-сборка GitHub Actions

Проект содержит `.github/workflows/build-apk.yml`. Workflow запускается автоматически после commit в `main` или вручную из вкладки Actions. Он устанавливает JDK 17, Android SDK 35 и Gradle 8.7, проверяет Package ID, версию и наличие ключевых исходников, затем запускает:

```bash
gradle clean testDebugUnitTest assembleDebug --no-daemon --stacktrace
```

После успешного завершения `app-debug.apk` появляется в разделе Artifacts.

Подробная инструкция: `GITHUB_UPDATE_GUIDE_RU.txt`.

## Подпись и приватность

В архиве находится `signing/secure-notes-debug.keystore`, используемый для подписи debug APK. **Репозиторий должен оставаться Private.** Не публикуйте keystore и не отправляйте секретный пароль уничтожения в GitHub issues, README или коммиты.

## Проверки

Проект включает JVM unit-тесты AES-GCM для заметок и потокового файлового шифрования, включая проверку tampering, truncation и недействительности уничтоженного in-memory ключа. Статические проверки и JVM-тесты не заменяют полную Android-компиляцию. Окончательный результат должен подтвердить GitHub Actions.
