# SecNote 1.4.4

Android-приложение для защищённых заметок и файлов.

- **Package ID:** `infernics.notes`
- **Версия:** `1.4.4` (`versionCode = 12`)
- **Минимальная версия Android:** 8.0 (API 26)
- **Compile SDK:** 35
- **Java:** 17
- **Gradle:** 8.7

## Изменения в 1.4.4

- Исправлена несовместимость зависимостей CameraX с Android Gradle Plugin 8.6.1 и Compile SDK 35: CameraX 1.6.2 заменён на CameraX 1.5.3.
- Сохранена кнопка камеры на главном экране непосредственно над кнопкой «+».
- Съёмка по-прежнему выполняется внутри приложения; JPEG шифруется AES-256-GCM и сохраняется в файловом хранилище без создания незашифрованного временного файла.

## Ранее добавленные возможности

- Импорт одного или нескольких документов прямо в зашифрованное хранилище без дополнительного диалога.
- Сохранение активной сессии при возврате из системного выбора файлов.
- Заметки и чек-листы с автосохранением и ручной сортировкой.
- Файловое хранилище с галереей изображений, экспортом и удалением.
- AES-256-GCM для заметок и файлов.
- Биометрическая разблокировка через Android Keystore.
- Секретный пароль экстренного уничтожения и блокировка снимков экрана.
- Светлая и тёмная темы и автоблокировка.

## Подпись и приватность

В проекте сохранён прежний файл подписи `signing/secure-notes-debug.keystore`, необходимый для установки обновлений поверх предыдущей сборки. Не заменяйте его. Репозиторий должен оставаться Private: не публикуйте keystore и секретные данные.
